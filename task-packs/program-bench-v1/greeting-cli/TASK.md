# Implement the greeting CLI

Implement `program.mjs` as an executable Node.js command. With exactly one argument it must print `hello ` followed by that argument and a newline. With any other number of arguments it must print a concise `usage:` message to stderr and exit non-zero.

Use the supplied `compile.sh` and public tests. Do not modify anything under `fixture/`. The native verifier will compile the submission and exercise additional inputs.
