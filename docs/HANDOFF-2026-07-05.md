## Batch B — Dashboard UI (do only after Batch A gate passes)

### B1 — Compact pressure banner (task #138)
- **Done:** `packages/dashboard/src/features/chat/Composer.tsx` exposes a manual compact icon button and treats exact `/compact` input as a command. Both paths fire `client:compact` instead of appending a user message. `ActivityBar` shows compact running and complete feedback.
- **Still open:** pressure-specific `ContextPressureBanner` behavior. Subscribe to `session.state.contextPressureLevel`. Amber bar with "Compact now" button when `'soft'`; red bar when `'hard'`.

### B2 — Streaming render + ESC cancel (task #125)
- Wire the `session:token_delta` handler in `app.tsx` — accumulator keyed by sessionId.
- Add `streamingText: string | null` prop to `ChatPanel`. Renders the live-updating assistant row; clears when the final `event:appended` for that turn arrives.
- Global keydown in `app.tsx`: if the current session is `thinking`, ESC fires `client:cancel_stream`.

### B3 — Permission-mode picker (task #126)
Popover with 4 rows (Auto / Ask everything / Deny / Allow all). Wire to `client:set_approval_mode`. `allow_all` needs a confirmation dialog (server also enforces `AK_ALLOW_ALL_OK=1`). Place next to the model picker in the composer footer chip row.

### B4 — Message editing + rerun (task #127)
Hover a `role: 'user'` row in `ChatPanel` → pencil icon → click opens inline textarea pre-filled. Submit fires `client:fork` at that message's cursor with the edited text seeded as the first user message of the new fork. Reuses existing fork protocol.

### B5 — Image paste (task #128)
In `Composer`, intercept `onPaste`; scan `clipboardData.items` for `image/*`; convert to base64; attach as `image` content blocks alongside the text. Preview thumbnails above the input with an X to remove. On submit, build `user_message` content as `MessageContent[]` (already supported via A6).

### B6 — `@file` fuzzy picker (task #129)
- New protocol event pair: `client:list_files { workspaceId, query }` → `server:file_list { workspaceId, entries: readonly {path, size}[] }`. Host walks the workspace root skipping `.git`, `node_modules`, `dist`, `.claude`, `references`. Cap results at ~200.
- Composer: typing `@` opens a popover. Enter/click inserts `@packages/foo/bar.ts` as literal text.
- On submit: composer resolves each `@`-mention to an inline `text` block `--- packages/foo/bar.ts ---\n<file contents>\n---`. Files > 64 KB rejected with a toast.

### B7 — Hooks system (task #130)
- Config in `~/.config/agent-kernel/config.toml`:
  ```toml
  [[hooks]]
  event = "pre_tool_use"
  match = "bash"
  command = "/path/to/lint.sh"
  ```
- Host loads on boot, keeps list in `runtime-config`.
- Reducer emits `pre_tool_use` / `post_tool_use` / `session_start` / `session_end` as observation events (or wrap in the host loop — kernel-purity says host loop is fine).
- Host maps events → matching hooks → spawns subprocess with JSON-piped payload. Non-zero exit blocks the tool call (host converts the tool call into a synthetic failed `tool_result`).

### B8 — Settings UI (task #131)
New route `/settings`. Sections:
- Models (list from `runtime-config.ts` providers; edit config.toml per-key).
- Approvals default mode.
- Hooks list.
- MCP servers (stub — reads/writes the field but explains runtime isn't wired).

Reuse form primitives from `packages/dashboard/src/components/ui/`.

### B9 — Session rename (task #132)

### B10 — cwd toolbar + metadata modal (task #133)

## How to run things

Everything is pnpm workspace, node ≥ 20.

```bash
# Kernel — pure, fast
pnpm --filter @agent-kernel/kernel build
pnpm --filter @agent-kernel/kernel test

# Shared — protocol types
pnpm --filter @agent-kernel/shared build

# Host — the daemon on :3000
pnpm --filter @agent-kernel/host build
pnpm --filter @agent-kernel/host test

# Executor — the tool runner
pnpm --filter @agent-kernel/executor build
pnpm --filter @agent-kernel/executor test

# Dashboard — Vite build → dist/, served by host
pnpm --filter @agent-kernel/dashboard build
```

**Running a full session locally:**
```bash
# Terminal 1 — host
pnpm --filter @agent-kernel/host dev

# Terminal 2 — executor
pnpm --filter @agent-kernel/executor dev

# Browser: http://localhost:3000
```

**Headless Chrome** already runs on `:9222` — use it for UI smokes. Existing smokes in `/tmp/ak-smoke-*.mjs` and `packages/dashboard/scripts/verify-*.mjs` show the pattern (CDP over WebSocket).
