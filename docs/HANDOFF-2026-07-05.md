### A9 — Background shell (task #143) — Claude Code pattern

**Reference behaviour from Claude Code / Codex:** `Bash` tool takes an optional `run_in_background: true` param. Instead of blocking until stdout completes, the executor forks, returns `{ ok: true, content: 'started bg task <id>' }` immediately, and streams stdout/stderr to a growing file. New tools `BashOutput(task_id, block, timeout)` and `KillShell(task_id)` let the LLM poll or stop. When the process exits, executor emits a `task-notification` (in our world: a `tool_result` follow-up? — or a new event kind). Design decision needed:

**Recommendation:** treat completion as a delayed `tool_result` on a NEW callId (assigned when the background task starts), and stream partial output via a new `ServerBackgroundOutput { sessionId, taskId, chunk }` event that the dashboard can render into an inspector panel. The initial synchronous `tool_result` for the `Bash` call returns the taskId. Followup `bash_output` / `kill_shell` tools take the taskId as input.

**Files:**
- `packages/executor/src/tools/bash.ts` — branch on `input.run_in_background`. When true:
  - Spawn as detached child, redirect stdout/stderr to `~/.ak-tasks/<taskId>.log`.
  - Track process in an in-memory `Map<string, ChildProcess>`.
  - Return synchronously with `{ ok: true, content: JSON.stringify({ taskId, note: 'started' }) }`.
- `packages/executor/src/tools/bash-output.ts` — new tool. Reads current log content since a given offset (state stored per (session,task) in-memory). Optional `block: true` blocks until the process exits or timeout.
- `packages/executor/src/tools/kill-shell.ts` — new tool. Kills the child.
- Register the two new builtins in `packages/executor/src/builtin-tools.ts` (or wherever the tool registry lives).
- Protocol: no new events strictly required — the polling design fits within existing `tool_result`. If you want live streaming to the dashboard, add `server:bg_output { sessionId, taskId, chunk }`.

**No kernel changes** — background shells are transparent to the reducer.

**Test:** `packages/executor/src/tools/bash.test.ts` — start a background `sleep 0.2; echo done`, immediately `bashOutput(block:false)` returns empty, then `bashOutput(block:true, timeout:1000)` returns "done".
