# @agent-kernel/eval-protocol

Browser-safe, versioned contracts shared by the standalone evaluation Dashboard, Control Plane, Workers, SDK, analyzers, and adapters. This package has no Node.js or Agent RunLab product-runtime dependency.

The standalone platform starts with canonical protocol version 1. Pre-refactor Host evaluation runs, sessions, and artifacts are not imported or parsed by this package; acceptance evidence is produced by fresh platform runs.
