Connection help

HTTPS is recommended for remote servers. HTTP remains available, but remote HTTP cannot use security-sensitive desktop integration. HTTP loopback origins such as localhost remain trusted for local development.

The app connects to your existing Dashboard and does not start a backend or open a port. A server is remembered only after the Dashboard connects successfully.

Press Ctrl+Shift+O to change server, Ctrl+R to reload, or Ctrl+Q to quit. External identity-provider redirects require HTTPS.
