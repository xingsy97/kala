Help and shortcuts

Remote servers require HTTPS. HTTP is accepted only on loopback. Do not include passwords, tokens, paths or query parameters.

The same React Dashboard, account sign-in, sessions and Runtime run on your existing Host. This app does not start a backend or open a port.

After a successful Dashboard connection, the server address is remembered and reused when you next open the app. Use Change server in the tray to edit it. A failed attempt does not replace your last successful server.

Workspace paths and terminals belong to the remote Runtime. Upload dialogs select files on this desktop. Your browser cookies are not imported.

Press Ctrl+Shift+O to reconnect, Ctrl+R to reload the Dashboard, or Ctrl+Q to quit. Closing or minimizing a window hides the app in a supported system tray; click its icon to return. If no tray host exists, closing quits and minimizing uses the normal taskbar. If tray confirmation stops responding, the window stays reachable instead of silently exiting. Tray Quit always exits. If the tray disappears, the app returns visibly. External identity-provider redirects require HTTPS.

Client package updates use your system package manager. A downloaded standalone .deb does not configure automatic updates.
