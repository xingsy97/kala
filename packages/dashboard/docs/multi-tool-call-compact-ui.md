# Multi Tool-Call Compact UI
  
  This note describes how the dashboard should present bursts of tool activity. Multiple related tool calls should collapse into a readable activity group by default while preserving the ability to expand and inspect each individual call and result.
  
  The compact row should show the activity title, operation count, status counts, and a short summary. Expanded rows should preserve tool name, input preview, status, and links to raw details. The UI must avoid horizontal overflow on mobile and must not hide failed or pending calls.
